# Mobile Legends: Bang Bang — Chronicles of the Land of Dawn

An award-winning interactive cinematic digital universe dedicated to **Mobile Legends: Bang Bang (MLBB)**. Built with React 19, Vite, Tailwind CSS v4, Three.js, React Three Fiber, Drei, Lenis, and the Web Audio API.

---

## 🌟 Visual & Cinematic Experience Overview

- **Section A — Cinematic Intro / Preloader**:
  - Dark screen with real-time floating golden & cyan ember particles.
  - Golden MLBB emblem monogram with pulsing celestial aura.
  - Dynamic progress indicator and "SKIP INTRO [ESC]" accessibility control.

- **Section B — Hero Landing Experience**:
  - Full-screen opening scene featuring iconic heroes (Alucard, Gusion, Fanny, Kagura, Granger, Chou, Beatrix, Tigreal).
  - Dynamic theme lighting and background aura adapting to the active hero.
  - Interactive hero switcher dock with mouse-responsive 3D parallax tilt.
  - Spoken battle cries, official lore quotes, and role/lane telemetry.

- **Section C — The Hero Archive**:
  - Comprehensive character discovery grid with instant search.
  - Role filters: Fighter, Assassin, Mage, Marksman, Tank.
  - Lane filters: Jungle, Mid Lane, Gold Lane, EXP Lane, Roam.
  - Tactical difficulty meter and sorting options (Win Rate, Difficulty, A-Z).
  - Rich artifact cards with zoom hover effects and action buttons.

- **Section D — Individual Hero Experience (Deep Chronicle Modal)**:
  - High-resolution hero splash art banner.
  - Origin story & biography verified with official game lore.
  - Character relationships matrix (Allies, Rivals, Mentors, Family).
  - Combat attribute breakdown: Offense, Durability, Ability Effects, and Difficulty ratings.
  - Available skins and quick shortcut into the 3D chamber.

- **Section E — Tactical Skills Lab**:
  - Interactive ability kit inspection (Passive, Skill 1, Skill 2, Ultimate).
  - Accurate cooldowns, mana/energy costs, damage classification, and tactical combat tips.
  - Real-time animated HTML5 Canvas FX visualizer rendering particle trails, slashes, daggers, and energy vortexes.

- **Section F — Interactive 3D Hero Chamber**:
  - Built with **Three.js**, **React Three Fiber**, and **@react-three/drei**.
  - Interactive OrbitControls (drag to rotate, pinch/wheel to zoom).
  - Holographic gyro energy totem and floating runic rings.
  - Auto-rotation, wireframe shading toggle, camera reset, and energy lighting color switcher.
  - Seamless toggle between 3D Holographic Chamber and 2.5D Artwork Perspective.

- **Section G — Lore / The World of MLBB**:
  - Illustrated Land of Dawn continent map with clickable territory pins:
    - **Moniyan Empire** (Capital of Light, Imperial Knights)
    - **Cadia Riverlands** (Eastern sanctuary of dragon arts & Onmyouji spirits)
    - **Eruditio** (Metropolis of clockwork engineering & scholars)
    - **Northern Vale** (Frostbitten fjord of titans & reavers)
    - **The Abyss** (Volcanic fissure of demonic corruption)
    - **Celestial Palace** (Floating sanctum of divine creators)
  - Chronological codex of major historical events from the Era of Creation to the Present Dawn Crisis.

- **Section H — Skins & Visual Evolution Vault**:
  - Showcase across cosmetic tiers: Legend, Collector, and Default.
  - High-res skin splash arts (e.g. Alucard Obsidian Blade, Gusion Night Owl, Granger Starfall Knight).
  - Compare button allowing immediate visual comparison between classic default and premium skins.
  - Interactive celebration confetti burst on skin inspection.

- **Section I & J — Final Cinematic CTA & Footer**:
  - Dramatic battlefield clash key visual backdrop.
  - Clean navigation, project credits, canon roster index.
  - Non-commercial fan tribute disclaimer acknowledging MOONTON Games copyright and trademarks.

- **Tactical Hero Compare & Global Search**:
  - Side-by-side hero comparison modal with attribute delta bars and matchup synergy insights.
  - Global `Ctrl+K` / `Cmd+K` keyboard shortcut for instant hero search.
  - Web Audio API procedural soundscape synthesizer: ambient drone + zero-latency UI sound effects without external audio asset dependencies.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Typography**: Google Fonts (*Cinzel Decorative*, *Cinzel*, *Outfit*, *JetBrains Mono*)
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Particle & Visual Effects**: HTML5 2D Canvas, `canvas-confetti`
- **Audio Engine**: Web Audio API (procedural harmonic synthesizer)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Navigate to project directory
cd "c:/Main/Git Project/Mlbb/Mobile-Legends-Desc-FW"

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
